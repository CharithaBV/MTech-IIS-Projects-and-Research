## Project Summaries

### 1. Thermal Imaging-Based Fault Detection in an Induction Motor
* **Course:** 20IS799 M.Tech Dissertation (June 2022)
* **Advisor:** Dr. T. Ananthan
* **Document:** [`Thermal-Imaging-Motor-Fault-Detection.pptx`](Thermal-Imaging-Motor-Fault-Detection.pptx)
* **Description:** Presentation for the M.Tech dissertation defense. Covers non-invasive condition monitoring of three-phase induction motors using FLIR thermal cameras. Demonstrates temperature distribution profiling for bearing faults, unbalanced supply, and stator overheating, followed by machine learning classification. Work published at IEEE ICESC 2022.

### 2. Silica Concentrate Prediction in Mining Process
* **Course:** 19AI716 Cloud and Big Data Analytics
* **Document:** [`BigData-Mining-Silica-Prediction.pptx`](BigData-Mining-Silica-Prediction.pptx)
* **Description:** End-semester project predicting silica impurity levels in iron ore flotation processes. Built an ETL and predictive pipeline using PySpark ML and Spark Streaming, deployed with GCP Dataproc, BigQuery, and Pub/Sub.

### 3. Cyber-Physical Intelligent Agents for Irrigation Scheduling
* **Course:** Architecture of Intelligent Systems (AIS)
* **Document:** [`Cyber-Physical-Irrigation-Agents.pptx`](Cyber-Physical-Irrigation-Agents.pptx)
* **Description:** Architecture design for automated agricultural irrigation using intelligent agents. Combines rule-based logic agents with crop water requirement simulation (FAO AquaCrop) to optimize watering schedules based on soil moisture and climate parameters.

### 4. Process Control & Monitoring of Three-Tank System
* **Course:** Fault Detection & Diagnosis / Process Control
* **Document:** [`Three-Tank-Process-Fault-Diagnosis.pptx`](Three-Tank-Process-Fault-Diagnosis.pptx)
* **Description:** Study on modeling and fault monitoring of the classic three-tank benchmark process. Analyzes mixed continuous and discrete system dynamics, sensor bias detection, and actuator fault isolation during continuous fluid flow.

### 5. Hybrid Neuro-Fuzzy Systems for Fault Detection & Isolation
* **Course:** Fault Diagnostic Systems (FDS)
* **Document:** [`Neuro-Fuzzy-Actuator-FDI.pptx`](Neuro-Fuzzy-Actuator-FDI.pptx)
* **Description:** Study of Adaptive Neuro-Fuzzy Inference Systems (ANFIS) for fault diagnosis. Evaluates symptom classification and continuous parameter regression, with a case study focused on fault detection in an electro-pneumatic control valve actuator.

### 6. Smart Greenhouse Automation using Industrial IoT
* **Course:** Embedded Systems Design (ESD)
* **Document:** [`Smart-Greenhouse-IoT-Automation.pptx`](Smart-Greenhouse-IoT-Automation.pptx)
* **Description:** Embedded hardware and gateway implementation for greenhouse monitoring and control. Interfaces sensors (temperature, humidity, soil moisture, light) to a Raspberry Pi running multi-threaded Python control routines for climate automation.

### 7. Security and Privacy of IoT Devices in Smart Healthcare
* **Course:** Ubiquitous Computing & IoT Security (701-UC)
* **Document:** [`IoMT-Security-Smart-Healthcare.pptx`](IoMT-Security-Smart-Healthcare.pptx)
* **Description:** Literature survey and risk analysis of Internet of Medical Things (IoMT) devices. Covers firmware vulnerability surfaces (including TCP/IP stack flaws like WRECK bugs), data privacy concerns, and security best practices in hospital networks.

### 8. Automated Parking Slot Allocation using RFID Technology
* **Course:** 20RM600 Research Methodology
* **Document:** [`RFID-Smart-Parking-Allocation.pptx`](RFID-Smart-Parking-Allocation.pptx)
* **Description:** Term paper and experimental study on parking slot management using RFID cards and transceivers, HT12E/HT12D RF encoders/decoders, and infrared slot detection to reduce search time and manual supervision in parking lots.

### 9. Music Genre Classification using Machine Learning
* **Course:** Machine Learning
* **Document:** [`Music-Genre-Classification-ML.pptx`](Music-Genre-Classification-ML.pptx)
* **Description:** Audio classification pipeline on the GTZAN benchmark dataset. Extracts time- and frequency-domain features (MFCCs, spectral roll-off, chroma) and benchmarks classification accuracy across multiple genres using standard machine learning models.
